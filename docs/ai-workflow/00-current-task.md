# Tarefa Atual

## Objetivo

Vamos construir um APP JAVA cli TODO list com armazenamento em arquivos .md.

## Contexto
A ideia é construir um pequeno app CLI que permita definir, armazenar, alterar e excluir tarefas com titulo e descrições detalhadas.
A linguagem deve ser java 21. E o armazenamento em .md + pastas.

Nesta primeira tarefa, construiremos apenas a estrutura básica inicial, e o módulo de criação e leitura básica das tarefas.
Neste momento elas não terão relação entre si, como a de sub-tarefas, apenas título e e descrições simples.
